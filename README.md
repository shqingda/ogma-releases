# Ogma releases

Release packages for Ogma, a terminal coding agent. The source code is developed in a separate repository; this one only hosts the published releases and their install script.

Install or update the latest release:

```sh
curl -fsSL https://github.com/shqingda/ogma-releases/releases/latest/download/install.sh | sh
```

An installed Ogma updates itself with `ogma update`.
